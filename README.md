# GMod Lua Executor (C++)

## Overview

This is a work-in-progress C++ project experimenting with DLLs, Lua integration, and runtime code execution.

The goal of the project is to understand how native C++ code can interact with a scripting language (Lua) at runtime.

---

## Features

* Basic DLL entry point
* File selection using Windows API
* Reads `.lua` files from disk
* Attempts to execute Lua code at runtime
* Simple hotkey trigger (INSERT)

---

## Status

⚠️ Not finished
This project is still in development and may crash or not function correctly.

## Requirements

* Windows OS
* C++ compiler (MSVC recommended)
* Visual Studio 2022
* Basic knowledge of C++ and Lua

## Known Issues

* Lua state is not properly initialized yet
* No proper error handling for Lua execution
* Potential instability due to threading and DLL entry usage
